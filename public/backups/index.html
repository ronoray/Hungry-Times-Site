Hungry Times · Owner-operated utility

A recoverable copy.
A clearer picture.

HungryTimes Backups keeps owner-selected files, application databases and configuration archives in Google Drive, with verification and status checks to help identify missing or outdated backups.

This is a private utility for the owner of Hungry Times and explicitly authorized operators. This public information page does not provide account registration or access to backup files.

01 / BACK UP

Keep a separate copy

Scheduled jobs on owner-managed computers and servers create and upload selected archives and database snapshots to the authorized Google Drive account.

02 / VERIFY

Check what arrived

Jobs inspect file metadata and, where configured, download copies to compare checksums. Monitoring reports freshness, transfer errors and backup availability.

03 / RECOVER

Restore when needed

The owner can download retained copies for recovery. Retention rules remove older backups according to the settings for each backup category.

How Google Drive access is used

The utility uses rclone, an open-source file-transfer tool, and Google's authorization process. Drive access supports listing backup files, uploading and downloading content, checking metadata, managing backup folders and removing old copies.

The requested Drive permission can technically allow access beyond individual backup folders. The configured jobs use it for the owner's selected backup, synchronization and recovery operations. The owner grants access in Google's browser sign-in flow and can revoke it in Google Account settings.

Google account passwords are entered with Google, not on this website. The backup scripts use OAuth credentials and tokens stored on the owner's managed systems.

Status notifications

Configured monitoring sends operational notices to the owner's private Telegram chat. These can include backup filenames, timestamps, sizes, freshness and error summaries. A fresh database file confirms that file's freshness; it does not by itself prove that every stage of a backup completed.
